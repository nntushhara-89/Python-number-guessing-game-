# Python-number-guessing-game
A beginner-friendly command-line game built with Python. The player
tries to guess a randomly generated secret number and receives hints
until the correct answer is found.

## Features

- Random secret number between 1 and 99
- Hot and Cold hints
- Repeated guesses using a while loop
- Automatic termination when the correct number is guessed
- Input validation for invalid entries

## Technologies Used

- Python 3
- Python random module

## How to Run

1. Install Python 3 if it is not already installed.
2. Clone this repository or download the project files.
3. Open a terminal in the project directory.
4. Run:

   ```bash
   python main.py
   ```

   On some Windows systems, use `py main.py` instead.

## How to Play

1. Run the program.
2. Enter a whole number between 1 and 99.
3. Read the hint:
   - **Hot:** The guess is within 10 of the secret number.
   - **Cold:** The guess is more than 10 away.
   - **You guessed it right!!:** The guess is correct.
4. Keep guessing until you win.
